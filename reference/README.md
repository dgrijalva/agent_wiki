# agent_wiki reference

This is agent_wiki's reference, written for agents. agent_wiki serves a folder of markdown as a website, and serves an MCP server so an agent and its user can work on the same documents.

Paths below are relative to this folder. Through the MCP, read them with `read_document` at `_wiki/reference/<name>`. Before agent_wiki is installed, read them on GitHub: https://github.com/dgrijalva/agent_wiki/tree/main/reference

- **[Using the MCP](using-the-mcp.md):** how to find, read and link to documents with the wiki's tools. Read this first if you are connected to a wiki.
- **[Using the site](using-the-site.md):** what the user sees in the web view, to help them find it and answer their questions.
- **[Onboarding](onboarding.md):** installing agent_wiki and setting it up for a user. Start here if the user asked you to set it up.
- **[Building your own application](building-an-application.md):** wrapping agent_wiki in an application of your own, to customize it.
